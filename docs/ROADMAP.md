# Roadmap

## Phase 1 — Trust and institutions

- Trust identity, registration, branding, contact, address, and status.
- Campus identity, location, contact, and status.
- Institution Type taxonomy.
- Institution identity, type, effective-dated campus assignments, affiliation/approval facts,
  branding, contact, and status.
- Trust Admin and Institution Admin access boundaries.
- Guided setup and readiness checks.

## Phase 2 — Institution settings

Design settings only after the foundation journey is complete. Settings must support inherited,
effective-dated values with an explanation of where each value came from. This phase will define
academic calendars, numbering, terminology, capabilities, and institution-specific form policy.

## Phase 3 — Admissions

Build admissions as a new vertical slice after settings are proven. Start from enquiry and end with
an admitted student/enrolment. Create only the masters that this journey consumes.
